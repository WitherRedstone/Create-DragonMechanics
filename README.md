# Create：冰与火（Create: Ice and Fire）

## 介绍

这是把《冰与火：龙之觉醒》和《机械动力》接在一起的一个小模组。
冰与火的龙煅炉需要一条被驯服的龙对着它喷火才能工作，现实中既难伺候、又占地方。 而机械动力本来就有一整套鼓风机气流系统，冰与火也本来就有现成的龙头骨——把这两样凑到一起，龙头骨就成了鼓风机的触媒：鼓风机把风吹过摆在地上的龙首，气流就变成了龙息。
于是你不用再养龙，摆一颗龙头骨在气流里，就能拿到火、冰、闪电三种龙息，用它加工物品、给龙煅炉加热、烧灼气流里的生物。
模组的定位很单纯：只做“龙首 + 鼓风机 + 龙煅炉”这一条线，不新增机器、方块和物品，配方也直接沿用冰与火自己的龙煅炉配方。


## 描述

模组把冰与火的三颗龙首做成了机械动力的鼓风机处理类型。龙首本身是一个实体，不会挡住气流，所以随便摆在气流路径上就行，也不占方块、不需要额外注册方块或方块实体。
三种龙息互相独立：火龙息对应火龙钢与火龙煅炉，冰龙息对应冰龙钢与冰龙煅炉，闪电龙息同理。龙种不匹配时气流照样存在，只是不会对那条炉子生效。
气流强度是有意义的：转速越高，物品加工越快、龙煅炉升温越快、生物的伤害和元素效果越强，粒子与音效也越密。转速太低时气流仍会带属性，但推进很慢。
在 JEI 里，模组为三种龙息各注册了一个“鼓风机处理”分类，内容读取的正是冰与火那三个龙煅炉的配方，所以整合包改动龙煅炉配方、增加新配方，这边会自动跟着变。

## 功能

**龙首触媒**：把火、冰或闪电龙的龙头骨摆进鼓风机气流，气流经过它之后就带上对应的龙息。触媒是实体不是方块，可以悬空、可以放在半砖上，气流不会被它挡住。
**按龙煅炉配方加工物品**：气流里飘着的物品会按冰与火龙煅炉的配方被加工，比如铁锭在火龙息里会变成龙钢锭，龙血之类的配方也同样适用。只看输入物品和龙种，不需要真的摆一台炉子——相当于把气流本身当成一台“无形龙煅炉”。
**给龙煅炉加热**：把对应龙息的触媒气流吹向龙煅炉，效果等同于真龙对着炉子喷火，会持续刷新炉子的火焰计时、推进烧炼进度直到出成品；气流撞在炉体外壳上、没直接吹进炉口时也能加热。输入不对或输出满了不会空烧，行为跟炉子原版一致。
**影响气流中的生物**：站在龙息气流里的生物会受到对应属性的伤害，并附带元素效果——火龙息点燃，冰龙息冻住，闪电龙息沿气流方向击退。伤害与持续时间随气流强度变化。
**侵蚀方块**：被龙息持续吹到的方块会按冰与火自己的规则转化（烧焦、结霜、雷击等）。只在游戏规则允许生物破坏方块时生效，并且会跳过龙煅炉与抗龙方块。
**视觉与音效**：气流中会生成对应元素的粒子，龙首会按间隔播放龙息音效（火、冰、闪电各不同，冰略低、闪电略高）；闪电龙息还会从龙首前方画出一道锯齿状闪电弧，一直延伸到气流尽头。
**JEI 支持**：三个“鼓风机处理”分类分别展示火龙息、冰龙息、闪电龙息的龙煅炉配方，分类图标是各自的龙首，界面里鼓风机前方会渲染出对应的龙头骨。
**龙煅炉自动化**：给龙煅炉核心与砖块补上了物品处理能力，可以用漏斗、机械臂之类的设备自动送材料、送血、取成品，不必手动塞。

**可配置**：`config/create_iceandfire-common.toml` 里分五组开关——是否启用三种龙息、是否启用物品加工与炉子加热、气流强度与射程、对生物的伤害与效果时长、是否允许侵蚀方块。默认全开。

## 用法

1. 造一台鼓风机，接上动力并设定朝向，让它吹出一条气流。
2. 把对应龙种的龙头骨摆进这条气流里（放在气流路径上即可，不需要贴着鼓风机）。放好后气流会立刻带上对应龙息，鼓风机每约一秒重建一次气流，所以摆放或打掉龙首后大约一秒内就能看到变化。
3. 想加工物品：把物品丢进气流，或用机械臂、传送带、漏斗把物品送进气流路径。物品会按冰与火对应龙种的龙煅炉配方变成成品。
4. 想给龙煅炉加热：让气流正对着龙煅炉的输入口吹（吹到炉体外壳上也可以），炉子就会开始正常烧炼；炉子需要先按冰与火的方式组装好并放入材料。
5. 想知道能加工什么：在 JEI 里搜“鼓风机处理”，三个分类分别对应三种龙息，里面就是可用的龙煅炉配方。
6. 想调节强度：提高鼓风机转速可以加快加工与加热、增强对生物的效果，降低转速则整体变慢；射程和伤害等也可以直接在配置文件里调。
7. 如果气流没有效果，依次检查：龙首是否真的在气流路径上、龙种是否和炉子匹配、对应龙息是否在配置里开启、游戏规则是否允许方块被侵蚀。
