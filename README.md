# Create：冰与火（Create: Ice and Fire）

## 介绍

这是把《冰火传说》和《机械动力》接在一起的一个小模组。
冰与火的龙煅炉需要一条被驯服的龙对着它喷火才能工作，现实中既难伺候、又占地方。而机械动力本来就有一整套鼓风机气流系统，冰与火也本来就有现成的龙头骨——把这两样凑到一起，龙头骨就成了鼓风机的触媒：鼓风机把风吹过摆在地上的龙首，气流就变成了龙息。
于是你不用再养龙，摆一颗龙头骨在气流里，就能拿到火、冰、闪电三种龙息，用它给龙煅炉加热、烧灼气流里的生物、侵蚀沿途的方块。模组的定位很单纯：只做“龙首 + 鼓风机 + 龙煅炉”这一条线，不新增机器、方块和物品。

## 描述

模组把冰与火的三颗龙首做成了机械动力的鼓风机处理类型（fan processing type）。气流在生成时逐格检查有没有触媒，一旦穿过龙首，后面整段气流都会带上对应元素，直到气流结束或被挡住。龙首本身是一个实体，不会挡住气流，所以随便摆在气流路径上就行，也不占方块、不需要额外注册方块或方块实体。
三种龙息互相独立：火龙息对应火龙煅炉，冰龙息对应冰龙煅炉，闪电龙息对应闪电龙煅炉。龙种不匹配时气流照样存在，只是不会对那条炉子生效。
龙息只做“加热”和“影响”，不做“替代”：物品该放进龙煅炉里烧的，还是得造一台龙煅炉，气流不会凭空把铁锭变成龙钢锭。这样既保留了冰与火原本的生产线，也让鼓风机只是一条省事的加热管。
气流强度（鼓风机转速）是有意义的：转速越高，龙煅炉升温越快、生物的伤害和元素效果越强，粒子与音效也越密。转速太低时气流仍会带属性，但推进很慢。

## 功能

**龙首触媒**：把火、冰或闪电龙的龙头骨摆进鼓风机气流，气流经过它之后就带上对应的龙息。触媒是实体不是方块，可以悬空、可以放在半砖上，气流不会被它挡住。
**给龙煅炉加热**：把对应龙息的触媒气流吹向龙煅炉，效果等同于真龙对着炉子喷火，会持续刷新炉子的火焰计时、推进烧炼进度直到出成品；气流撞在炉体外壳上、没直接吹进炉口时也能加热。输入不对或输出满了不会空烧，行为跟炉子原版一致。只有**四级及以上**的龙首才有这个本事——幼龙、青年龙的头骨吹出的气流依然伤人、依然侵蚀方块，但推不动炉子。
**影响气流中的生物**：站在龙息气流里的生物会受到对应属性的伤害，并附带元素效果——火龙息点燃，冰龙息冻住，闪电龙息沿气流方向击退。伤害与持续时间随气流强度变化。
**侵蚀方块**：被龙息持续吹到的方块会按冰与火自己的规则转化（烧焦、结霜、雷击等）。只在游戏规则允许生物破坏方块时生效，并且会跳过龙煅炉与抗龙方块。
**视觉与音效**：气流中会生成对应元素的粒子，龙首会按间隔播放龙息音效（火、冰、闪电各不同，冰略低、闪电略高）；闪电龙息还会从龙首前方画出一道锯齿状闪电弧，一直延伸到气流尽头。
**龙煅炉自动化**：给龙煅炉核心与砖块补上了物品处理能力，可以用漏斗、机械臂之类的设备自动送材料、送血、取成品，不必手动塞。

**可配置**：`config/create_iceandfire-common.toml` 里分五组开关——是否启用三种龙息、是否启用炉子加热、气流强度与射程、对生物的伤害与效果时长、是否允许侵蚀方块。默认全开。

## 用法

1. 造一台鼓风机，接上动力并设定朝向，让它吹出一条气流。
2. 把对应龙种的龙头骨摆进这条气流里（放在气流路径上即可，不需要贴着鼓风机）。放好后气流会立刻带上对应龙息，鼓风机每约一秒重建一次气流，所以摆放或打掉龙首后大约一秒内就能看到变化。
3. 造一台冰与火的龙煅炉并组装好，放入输入材料与龙血。
4. 让龙息气流正对着龙煅炉的输入口吹（吹到炉体外壳上也可以），炉子就会开始正常烧炼，和真龙喷火的效果一样。注意只有四级及以上的成年龙首才能加热炉子，小龙头骨吹出的气流只伤人和侵蚀方块。
5. 想调节强度：提高鼓风机转速可以加快炉子加热、增强对生物的效果，降低转速则整体变慢；射程和伤害等也可以直接在配置文件里调。
6. 如果气流没有效果，依次检查：龙首是否真的在气流路径上、龙种是否和炉子匹配、对应龙息是否在配置里开启、游戏规则是否允许方块被侵蚀。
